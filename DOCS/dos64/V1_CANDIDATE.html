Source-built development candidate

Development note: see current status, build instructions and installation for present qualification. Historical measurements below apply to their stated slice, not every current build.

make v1-candidate DOS64_V1_CANDIDATE_ARGS='--runtime-media' builds twelve matched native files from public-layout source: SETUP.PRG/FAT/PUB, CONFIG.PRG, DOS64.PRG/REL/MNU and START.TPL/REL/INO/RCV/RFW. It requires Python, make, cc65, ca65, ld65 and none.lib. It needs no DOS images, vendor programs, private fixtures, Peddle, Zig or device access. Explicit DOS64 tool overrides remain supported.

The enabled chain builds the actual runtime with floppy FORMAT and original-8088 DEBUG tracing, then its exact cold eight-asset bundle, then release-bound cold56/20KiB SETUP with complete file diagnostics and CONFIG with moved-folder support and complete file diagnostics. Named metadata is checked inside the immutable cold run; all source/product identities and exact inventories are verified before packaging. build/v1-candidate/RESULT.json points to a fresh run containing the package, verified ZIP, component receipts and commands. Failure preserves the prior passed pointer and artifacts. Package BUILD.json excludes private absolute paths and marks V1/physical qualification false.

The existing command without --runtime-media retains the nine-file INI-only development profile. make v1-package-tests follows the requested candidate arguments; host tests also accept DOS64_CANDIDATE_RESULT to inspect a separate build. Tests corrupt private copies only.

The package README documents the native hotkey, Save/Save as/Insert, session Eject/protect, conditional Resume and Finish. All twelve files belong in a new folder with separately supplied user DOS sources. The configured START and disks are generated by SETUP; they are not distributed in the ZIP. Compiler success and host packaging checks do not qualify this exact rebuilt package. Physical Turbo workflow evidence exists on development fixtures; native 2 MiB installation passes, while native 20 MiB WRITE_NEW/UCI03 and CONFIG/media/Finish/human qualification remain open. The current source-built package matches the reviewed private candidate byte for byte and passes 25 host packaging controls. Its actual generated installation reaches genuine DOS and native Finish in the model; physical and human acceptance remain required. See the promotion receipt (local development record, not distributed).
