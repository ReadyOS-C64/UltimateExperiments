# Standalone native floppy export fixture

> Development note: see [current status](STATUS.md), [build instructions](BUILD.md) and [installation](INSTALL.md) for present qualification. Historical measurements below apply to their stated slice, not every current build.


`python3 build_support/build_floppy_export.py` builds the disabled-entry source-complete fixture; `zig build floppy-export --summary all` runs its actual6502 Peddle tests. Root registration reuses its single resolved target through `@import("tests/floppy_export/build.zig").add(b,target)`. `build_support/floppy_export.mk` exposes optional build/test commands. The standalone entry loops without storage operations; tests explicitly call linked native routines.

The FILE_INFO successor creates only a fresh owned path with mode6 (WRITE2|CREATE_NEW4), writes720sectors from REU, CLOSE/reopens READ1, requires exact successful FILE_INFO declared LE32size0005A000h, compares all368640bytes, probes one-byte EOF and requires known final CLOSE. It preserves original REU authority on failure and retains uncertain output/path. It never overwrites, truncates, deletes or renames output. Verification is logical metadata/content/closure evidence; it does not mark native media clean, establish power-loss durability or exclude external mutation.

Measured standalone exporter1334code/164state bytes, existing REU182bytes, UCI1265 and enabled FILE1170. No newZP; standalone REU uses4bytes. Disabled PRG3968bytes SHA256 `96c3491b10b80d212b222d4910c57b40418f11db5c6cb3a6498b8ec9dc7cea6d`. Buffers remainC100–C8FF and standalone compare staging8000–81FF. The builder explicitly enables DOS64_FILES_INFO=1; default-disabled FILE adapter preserves reviewed recovery helper identity.

The focused suite passes12Zig/Peddle tests/40actual scenarios and5clean-source packaging tests. Scenarios include whole360KiB A/B/target1or2/pathboundary success, banking preservation, all file phases including INFO, existing destination protection, silent partial WRITE now detected by declared size, corrupt/short/extra readback, DMA failures, cancellation, elapsed bounds, stuck firmware and unknown cleanup. Full4MiB source authority and native write guards remain asserted. Maximum standalone poll6456modeled CPUcycles excludes DMA stalls/physical timing.

Real paused native integration is separately described in [NATIVE_SAVE_IMPLEMENTATION.md](NATIVE_SAVE_IMPLEMENTATION.md): seventh SAVER asset atREU343000/B000, temporary borrow only while paused, real CIA clock,32normal guest-cache frames retained. This fixture alone supplies no native UI or media-generation binding. Modeled success does not transfer to physical installed-firmware acceptance or IEC.

READ error can leave status unpublished, so EOF alone is insufficient: fresh FILE_INFO declared size is now mandatory. Physical acceptance still requires independent full retrieved size/content comparison.
