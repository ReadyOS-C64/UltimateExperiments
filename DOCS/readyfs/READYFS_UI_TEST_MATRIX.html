ReadyFS UI Test Matrix

Target: 60 numbered UI cases. Status is updated from generated reports, not assumed from implementation.

Shell and editor (01–12)

  1. Boot banner, standalone identity, and REU status.
  2. Help opens and lists canonical endpoints.
  3. Unknown command reports an error and returns to prompt.
  4. Empty command is harmless.
  5. 255-byte logical line reaches the parser without overflow.
  6. Horizontal editor scroll follows the cursor.
  7. Left/right insertion edits the middle of a command.
  8. Insert/overwrite toggle changes replacement behavior.
  9. Delete and Home/End behavior.
  10. Up/Down recalls and edits command history.
  11. Page Up/Page Down and C= fallback traverse scrollback.
  12. Quoted arguments, spaces, and malformed quote diagnostics.

Paths, aliases, and matching (13–24)

  1. IEC endpoints accept 8 and 30 and reject 7 and 31.
  2. Ultimate root and USB1/SD-card absolute paths.
  3. SoftIEC partition 0 and 255 boundaries.
  4. Tape endpoint capability query.
  5. Alias create/list/use/remove.
  6. Alias expansion cannot escape its root in automation mode.
  7. ! distinguishes image host and internal names.
  8. Invalid image boundaries are rejected before I/O.
  9. * and ? component matching.
  10. ** recursive matching.
  11. --include/--exclude full-relative-stem filtering.
  12. Native-pattern mode stays distinct from shell matching.

Discovery and metadata (25–34)

  1. probe uci absent path in VICE.
  2. probe udos identify on C64U.
  3. probe softiec active and module-not-loaded outcomes.
  4. drives scan covers IEC 8–30 and returns to the prompt.
  5. IEC D64 directory and blocks free.
  6. IEC D71 16-bit blocks free.
  7. IEC D81 directory over 30 entries.
  8. UltimateDOS host directory over 30 entries.
  9. stat reports type, raw/display name, exact/estimated size units.
  10. volume/free distinguish host, image, and C64 block units.

Safe mutations (35–48)

  1. new creates an empty SEQ file.
  2. write --line creates expected bytes.
  3. append --line preserves old bytes and adds new bytes.
  4. Same-backend staged copy and verification.
  5. IEC-to-IEC cross-device copy.
  6. IEC-to-UltimateDOS copy.
  7. UltimateDOS-to-IEC PRG copy preserves bytes/type.
  8. UltimateDOS-to-SoftIEC copy.
  9. Recursive UltimateDOS-to-SoftIEC tree.
  10. Move deletes source only after verified copy.
  11. Replacement rollback preserves old destination on failure.
  12. Delete prompt defaults to no.
  13. Recursive delete summary and --yes behavior.
  14. REL cross-backend copy rejects with an explicit capability error.

Dry-run, mounts, batch, and recovery (49–60)

  1. Delete dry-run reports zero writes/deletes/mounts.
  2. Copy dry-run enumerates sources/destination/conflicts without writes.
  3. Move dry-run leaves source and destination unchanged.
  4. Recursive dry-run applies filters and leaves trees unchanged.
  5. Ultimate image mount/dismount on disposable image.
  6. Ultimate disk swap command.
  7. SoftIEC partition map/unmap under owned root.
  8. SD2IEC-compatible image mount/root/unmount sequence.
  9. Batch onerror stop and continue behavior.
  10. Batch expected-result journal and report conversion.
  11. UCI transport recovery followed by a successful identify at 1/16/64 MHz.
  12. Configuration restoration and owned-root preservation after forced suite failure.
