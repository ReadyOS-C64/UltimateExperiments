SuperEditor standalone keys

Attach the D81 as drive 8, enable a REU, then enter:

LOAD"SUPEREDITOR",8,1
RUN

Use a 16 MiB REU for the full development configuration. Reduced-capacity and 64KiB document checks are recorded separately in the acceptance evidence; the full font image does not start with 512 KiB. Files contain raw PETSCII source. VICE's PC-key mappings depend on its keyboard configuration; these labels refer to C64 keys.

Key Action
F1 Menus; type a menu letter, then an item letter
F6 Keyboard help; F6 again closes it
F7 Typed command; Return runs it, RUN/STOP cancels
F8 / CTRL-F8 Next / previous display mode: 40, 60, 80, GEOS
F4 Toggle soft wrapping
Cursors Move the source caret; up/down retain the preferred horizontal position
F3 / F5 Page up / down
HOME / CTRL-E Start / end of source line
SHIFT-HOME Top of document
CTRL-J / CTRL-L Jump backward / forward 40 source characters
CTRL-A / CTRL-W Previous / next word
Return / DEL Insert newline / erase previous character
SHIFT-DEL Insert a space; forward deletion is Edit→D or F7 delete
F2 Mark/unmark a selection; move the caret to extend it
RUN/STOP Clear a source selection; close a menu or prompt
CTRL-C or CTRL-K Copy selected canonical source
CTRL-X / CTRL-V Cut / paste
CTRL-Z / CTRL-Y Undo / redo
CTRL-O / CTRL-S Open / save
CTRL-G / CTRL-F / CTRL-N Go to line / find / next match

For example, F1,F,O opens a file and F1,F,A opens Save As. In a file dialog, type a name and press Return; DEL erases, up/down choose a listed name, F3 selects drive 8/9, F5 changes directory page, F6 shows dialog help, and RUN/STOP cancels. A dirty Open asks S to save, D to discard, or C to cancel. Opening a different file begins a fresh Undo history.

Useful F7 commands:

mode 40          mode 60          mode 80          mode hires
top              bottom           home             end
goto 25          jump -40         jump +40
find text        findi text       next match
wrap on          wrap off         pan left         pan right
mark             copy             cut              paste
undo             redo             delete           clear undo
open             save             save as
fold             fold all         unfold all
preview          source           settings         diag
syntax plain     syntax markdown  syntax full

findi ignores case. pan left/right enables the unwrapped view and moves 20 columns in the text views or 20 pixels in GEOS. Manual panning may hide the caret; ordinary source navigation reveals it again. A capacity error refuses the new edit before changing the source or existing pending edit; Undo remains usable.

Editable GEOS keeps source markers visible. F7 preview opens a separate, read-only formatted view: F3/F5 or up/down change pages, Return or RUN/STOP returns to source. F7 source toggles source/preview in GEOS, so it also returns when used from preview. Menus/help remain available. Formatting controls are hidden only in preview; saved files retain the original source.

The View menu provides these routes too: F1,V,P toggles GEOS preview/source; F1,V,S opens preview appearance settings. Preview requires GEOS mode. Closing Settings opened from preview returns to that preview. In Settings, H cycles Plain → Markdown → Full source processing. This is a different key context from View/H, which selects GEOS mode. Settings is available in every source mode.

F7 syntax plain (also syntax off) disables source syntax parsing and code coloring. syntax markdown keeps structural/inline formatting without BASIC or assembler token colors; syntax full (also syntax on) enables both. Plain shows source expanded while preserving stored fold choices for the other presets. Formatted preview remains a separate view; these controls do not edit the file.

F7 fold toggles the region at the caret. Fold summaries show an inverse +; selection, copy/cut and saved files still refer to the complete source. Direct GOTO/find into hidden text opens its ancestors. Arrow/page navigation skips collapsed bodies. To expand one region, use fold again; the parser has no standalone unfold alias. unfold all expands all regions. Fold summaries do not show a hidden-line count, and cut/delete does not add a confirmation prompt; check the selection before editing, and use Undo to restore it.

While typing, an unfinished code fence or region marker can temporarily make a fold map impossible to rebuild. An automatic rebuild then shows the expanded source so editing can continue. Explicit fold all still reports malformed fold syntax; source-read failures also remain errors.

F7 settings changes preview profiles: 1–8 choose Body, H1–H6, Code; F changes font, S size, C/G ink/paper, B/I/U bold/italic/underline, H source processing, R restores the compiled appearance and source-processing defaults, Return closes, and RUN/STOP closes without reverting choices already applied. These settings last only for the session. See GEOS preview and appearance for the actual font catalog and C64 color constraints.
