Ultimate Experiments

Source repository on GitHub

Outside ReadyOS—and sometimes before ReadyOS—we do random experiments for the Commodore 64 Ultimate. Some may become supported projects; some are one-offs and throwaways. These guides describe what each experiment currently does and how to try it.

ReadyFS in pictures

The editor and filesystem walkthrough follows help, editing, history, previews, transfers and a parameterized backup script. The SD2IEC walkthrough follows real native folder and image operations. Every step includes a command, explanation and actual C64 screenshot. No video files are needed or bundled.

Main disk images

  • ReadyFS overlay shell: the main interactive build and all 28 sidecars; at least 1 MiB REU.
  • ReadyFS monolithic diagnostic: the earlier, simpler reader.
  • ReuSQL64 interactive shell: SQL client and engine overlays; 512 KB–16 MB REU.

Read each project guide before loading an image. For filesystem writes, use disposable fixtures and follow the ownership rules. REU database state needs an explicit checkpoint/capture workflow to survive reset.

Read offline or publish

Every reference has a Markdown source and an HTML edition. Open index.html for the website, or browse the Markdown files directly. Images, styles and downloads are local; there is no runtime CDN dependency. The portable ReadyFS guide embeds its illustrations for printing and single-file offline reading.
