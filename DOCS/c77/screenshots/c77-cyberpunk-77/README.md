# ReadyOS C77 Cyberpunk 77 preview

These captures use:

- ReadyOS `precog-d81` 0.5 full D81
- VICE 3.10 with 1581 fast traps and warp mode
- `c77-photo-reconstruction-v2-chargen.bin`
- `C77CYBER.VPL` with VIC-II saturation set to 80% to avoid CRT-transform clipping

The VPL preserves ReadyOS's semantic color-number roles:

| C64 index | ReadyOS use | Cyberpunk 77 color |
|---:|---|---|
| 0 | black | near-black `#020205` |
| 1 | normal foreground | C77 yellow `#FCEE09` |
| 2 | error | neon red `#FF2A68` |
| 3 | selection/highlight | neon blue `#35C8FF` |
| 4 | purple accent | neon violet `#B64DFF` |
| 5 | green-role accent | electric blue `#5E8AFF` |
| 6 | TUI background | blue-black `#080B18` |
| 7 | title | pale yellow `#FFF368` |
| 8 | orange-role accent | amber yellow `#FFB800` |
| 9 | brown-role accent | dark ochre `#7A6118` |
| 10 | light-error accent | neon pink `#FF62B0` |
| 11 | darkest gray | charcoal `#20242D` |

contains nearest-neighbor enlargements, and `contact-sheets` contains readable
