# CIA delivery contract for this model driver

A single return to `modal_wait` does not guarantee a keyboard scan: a pending native clock sample can return first. The rejected helper released/pressed every matrix for one poll. Exact original chronology produced no DC01 reads for L/A/N/K/./I/M and submitted `/Home/SWAPG` instead of the seeded `/Home/SWAPBLANK.IMG`.

Hold EACH release and EACH pressed matrix until at least nine additional CIA1 DC01 reads have occurred. Bound this to 256 modal-wait iterations; validate returned PC/status each iteration. A normal full scan here reports ten reads, so a key plus its release usually reports twenty. The count is an observation of real native scanning, not an injected key/event/private intent. Keep Run/Stop and leaf budgets intact.

Before Return in the path editor, compare the exact native private 128-byte `_path` field with the canonical requested path and zero padding. Its address7B81 is derived from the exact generated panel assembly's BSS layout and independently checked against every existing exported BSS label (PANEL_PRIVATE_LAYOUT.json). This is a host oracle, never native authorization. Do not use a global screen substring or assume a typed prefix was accepted.

DOS BIOS keyboard delivery uses the separate actual command/ACK and ring observation. Queue each word once; condition-false is an observation, not success or permission to requeue. Require active footer/cursor and empty ring before program-specific Return. Preserve the same live VM on host-oracle failure.

Capture read-only RAM/REU/context, retain the active GUI callback, and use actual CIA Return and Finish only when the private UI accepts them. Unknown/fatal native state remains frozen; never reset/reopen for convenience. The focused missing-path and exact dropped-path controls demonstrate actual Return→Finish/known closure.
