# Native elapsed time, PIT and original-8088 IRQ delivery

> Development note: see [current status](STATUS.md), [build instructions](BUILD.md) and [installation](INSTALL.md) for present qualification. Historical measurements below apply to their stated slice, not every current build.


Accepted in the five-overlay Peddle target on 2026-10-15. Evidence (local development record, not distributed) pins sources, binaries and checks. Physical acceptance still belongs to the earlier three-overlay target.

The native scheduler samples the exclusively owned chained CIA2 clock before ordinary guest execution and while HLT is waiting. PIT channel 0 models binary mode 3 with fixed divisor 65,536. The exact nominal PAL conversion ratio is 546875/451572; state retains the raw epoch, rational remainder, oscillator phase, period total and next-edge countdown. The fast no-edge path and frozen full converter have independent actual-assembly differential tests. Byte zero writes to40h can rewrite the same low/high fixed divisor without restarting the oscillator; reads, word access, changed divisors and channel0 control programming remain unsupported. The unmerged speaker test candidate separately accepts write-only42h data and43h=B6h without changing channel0. Neither profile supplies general programmable PIT counters or oscillator-level bus timing. See [the current port contract](PORTS_IMPLEMENTATION.md).

Each observed edge requests IRQ0 in the modeled PIC. Multiple missed periods coalesce in IRR; there is no invented catch-up queue. CPU acceptance respects IF, pending prefixes, HLT and original repaired-NMOS interrupt shadows. Original segment MOV/POP shadows apply to all segment registers; STI shadows only the IF 0-to-1 transition. These details are source-derived, with disclosed historical silicon evidence gaps. Ordinary hardware interrupt frames use the mutable guest IVT and normal stack writes. A partial fatal frame failure is terminal, never a replayable successful interrupt.

REP keeps a maximum of 16 elements per CPU call. A real callback follows every eligible completed element, including comparison termination and before CX-zero handling. Interrupt acceptance stops that sequence, preserving the original IP-minus-two last-prefix restart and loss of earlier prefixes. The overlay lease is released before guest execution. Independent review interrupts element 16 with CX=33 and verifies exactly 16 commits, 17 remaining and the restart frame.

Default guest INT 08h at F000:01A0 executes STI, PUSH AX, the owned F8h clock gate at F000:01A2, INT 1Ch, PIC EOI, POP AX and IRET. INT 1Ch at F000:01C0 defaults to IRET. Only execution of that owned clock gate advances BDA time by one tick. A replacement INT 08h suppresses the BIOS update unless it chains; guest code owns EOI. INT 1Ah remains the original XT state API, separate from oscillator conversion.

Explicit development SNAPSHOT/RUN rebases raw time and discards the unobserved pause interval while retaining oscillator phase/PIC state. A transient coherent-sample rejection leaves RUN pending; callers poll that same command under a finite bound. Control/ownership failure or an observed gap above 32767×4096 raw ticks is fatal. A completely missed raw-clock wrap cannot be detected from the sampled word; bounded caller cadence remains a precondition.

`make test-timer-threshold` runs seven opt-in differential blocks against a separately assembled frozen converter. Root default checks and the exact 5,701-case reviewed CPU build pass; hardware-case masks were not relaxed. Native DOS observes 666 PIT periods and 590 guest BDA updates, exposing coalescing rather than equating the counts. Already-loaded NOP costs 796 Peddle CPU cycles; timer-plus-NOP costs 2141–5283 over measured no-edge deltas. These exclude DMA stalls and physical contention. Near-XT throughput remains unproved; trap/NMI/prefetch timing is incomplete.
