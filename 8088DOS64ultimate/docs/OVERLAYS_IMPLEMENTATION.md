# Native FILE/TEXT/INPUT code overlays

The resident manager loads one of three separately linked payloads into the exclusive1792-byte C900–CFFF window: FILE1088, TEXT957 (renderer718+display239), INPUT882. State is resident; wrappers hold the busy lock for the entire callback. Overlaid return addresses/function pointers cannot survive replacement. Busy/reentry/origin errors precede other checks. No IRQ/NMI may share the manager/cache/REU/C000 owner.

Each payload has a16-byte identity/version/exact-length/run-address header in its own2048-byte immutable REU slot:340000,340800,341000. Packaged source slots are6000,6800,8000. Bootstrap validates all headers before DMA and publishes readyA5 only after all three transfers. INPUT occupies the first four guest cache frames at startup: bootstrap must precede all guest cache/BIOS accesses. Cache initialization only touches metadata; it must not imply the source asset is disposable. Successful bootstrap releases6000/6800/8000 assets, not the separate cold lifetime.

Acquisition invalidates current identity before replacement, checks the REU header, transfers exact canonical length and publishes identity only on success. Partial DMA never enters replacement. Same-image hits avoid DMA. Assets are trusted immutable; native metadata validation is not a payload CRC. Independent build checks compare every packaged byte, header, gap/tail, fonts and cold image. Only the three alternative payloads may overlap.

BIOS init, bootstrap bodies, importer code/state and patch data use7000–7FFF before bitmap ownership. Initialized resident cold_openA5 is loaded with a fresh PRG; release clears it irreversibly and requires ready BIOS/overlays and no active importer/overlay. No init API reopens it. Resident gateways reject late calls before touching discarded bytes; BIOS additionally requires committed overlays. TEXT setup/restore/row calls require cold_open zero before loading/executing display code. FILE and INPUT retain their own lifetime contracts. Repeated release and ready-hit bootstrap are resident-safe after all cold bytes become BRK traps.

RAM+I/O, exclusive REU/UCI/scratch ownership and declared minimum4MiB remain caller preconditions. Wrappers preserve native P except carry and clobber A/X/Y; each direct ABI is separately tested under a held lock. Cold state is not resident metadata available after release.
