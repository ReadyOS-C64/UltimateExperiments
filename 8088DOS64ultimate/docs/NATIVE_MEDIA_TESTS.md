# Optional native media tests

`make test-native-media` builds a separate development profile, compiles its firmware model from source and runs27 actual6510/Peddle groups: A/B selection5, cancellation4, online-C10, outputCRC5 and direct Zig3. Disks are deterministic synthetic byte arrays. No supplied DOS images, vendor files, private research folders, network or device access are required.

The optional profile enables `DOS64_SAVE_HD_CONTEXT=1` and `DOS64_EXPORT_CRC=1` in a fresh staged native project. The normal build keeps both disabled and its existing bytes. `make native-media` builds/verifies that profile without running models; no Zig, C++ compiler or model resources are needed for that native-only path. Full tests require Python3.9+, make, ca65, ld65, a C++20 clang++ and the project's Zig0.16 toolchain. Set `DOS64_ZIG`, `DOS64_CLANGXX`, `DOS64_CA65`, `DOS64_LD65` or `DOS64_MAKE` for explicit tools. The normal Makefile's Zig lookup works in the standard checkout layout.

Use `DOS64_NATIVE_MEDIA_ARGS="--out /an/empty/or/native-media-owned/folder"` to select results. Each invocation uses a new run/workspace; native outputs never replace the normal build's main/unit images. `build/native-media/RESULT.json` is an atomic pointer to the newest fully verified run's eight immutable native products. Sources, compiler resources/tools, command logs, before/after input/product hashes and test reports are retained in that run. Before the final pointer commit, failure or cancellation leaves the previous passed result/products intact and retains run FAILURE/LAST_FAILURE. A host lock cleanup failure is reported honestly; it does not publish success or delete another owner's lock. An interrupt delivered after an atomic commit may leave the complete new result; a partial product set is never published.

Optional builder controls: `python3 -B tests/native_media/test_builder.py`. They exercise13 host groups including interrupted publication, double failures, failed copy/mkdir/unlink, source and product mutation, owner/path rejection, cache/environment isolation and real native-only/default builds. `python3 -B build_support/native_media_tests.py --native-only --default-profile --out build/native-media-default` gives a separate default-byte proof. Native-only results have an empty groups object; they are build/memory checks, not executed model tests.

The explicit source inventory stages normal native sources and pinned Peddle sources. Existing `tests/config/support` headers remain unchanged. Only two dedicated model overrides add ordinary WRITE05, close-failure injection and handle-position observation; their matching canonical base identities are checked. No opaque model library is shipped. New source package files are text; the native build reuses the existing CP437 font resources.

These are SaveAs checkpoints: new owned paths use CREATE_NEW, online C's handle/position/context survives only known-closed alternate-target use, and A/B can read complete360KiB media at REU100000/180000/380000. Source descriptor/policy/mount/content snapshots are captured before borrowing memory and checked again before native success. SaveAs permits readonly or clean media and preserves readonly/dirty/clean-generation/binding state. A fully verified file CRC alone does not establish a selected-media receipt after metadata changes: require current native ACK A5, sav_error0, exact captured media identity/generations and known final closure. CRC00000000 is valid. Partial/canceled CRC is diagnostic.

No CLEAN, CFG publication, backing-path change, persistent Save, Discard/Swap user menu, physical acceptance or V1 completion is claimed. Genuine DOS and Turbo Pascal workflows remain separate acceptance lanes. Model CPU clocks are not physical Ultimate time or an XT performance comparison.
