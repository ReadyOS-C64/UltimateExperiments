# Bounded proportional line layout and source hit testing

Executable micromodule `line.s` plus included `line-map.s`, with API in `line.inc`. Exports `se_geos_line_begin`, `step`, `finish`, `hit`. Actual linked fixture2755 bytes: pure line CODE1479 plus unchanged measure348, packed/width assets872 and shared converter56. No resident BSS/ZP, source/REU/DMA/pixel/port/VIC writes, parser/marker hiding or source mutation. Uses the existing glyph service's two borrowed pointer pairs (four existing bytes). No raster service is required.

Caller owns a foreground832-byte phase frame. Default `GEOS_LINE_FRAME=8D00`, ending903F; X/Y must equal that compiled address on every API entry. Optional compile-time placement must remain within8D00..917F. It contains77-byte GG metric scratch and321 boundary words (642 bytes). Suggested disjoint packet buffers9040/9060/9080 supply32 native bytes/styles/advances; native measure requires only the first two. Source input and font spans must be stable accessible RAM, valid/nonoverlapping with mutable frame; this API is not an allocator or arbitrary pointer validator. Parent must guard document/provider epoch/revision and own the derived phase/leases. The module owns no lease and cancellation discards its caller frame.

BEGIN takes mode0 wrap or1 no-wrap, encoding0 actual native/style measurement or1 supplied advances, viewport width1..320, canonical24-bit source start/caret,24-bit horizontal pan and the existing font/width/native pointers. Native encoding calls the unchanged `se_geos_measure` and shared PETSCII converter; styles0..3 add the actual bold1/italic2 advances. Supplied encoding accepts positive1..255 pixel advances. The supplied source byte still identifies literalSPACE32 and CR13. No byte/delimiter is hidden, normalized or modified.

STEP accepts at most32 native bytes with `GL_PACKET_AT==GL_SCAN`. Each packet returns used bytes and updated canonical scan anchor, so source reads can be resumed with bounded packets. Offset mismatch returns74. State1 means continue; state2 publishes a line with reason CR1, EOF2, FULL3, WORD4, HARD5 or OVERWIDE6. FINISH is the explicit EOF operation while streaming. Invalid state returns70, scalar/style/advance inputs90, coordinate/source overflow7B. A packet is streaming rather than transactional: a later invalid item may leave an accepted prefix; Cset must be handled by the caller.

Wrap retains the last accepted nativeSPACE opportunity across packet seams. Before overflow it publishes through that space, otherwise hard-breaks a long word before the overflowing glyph. The first overwide glyph is accepted alone, guaranteeing forward progress. EXACT width publishesFULL immediately. A followingCR or EOF therefore begins a genuine blank next line, matching the current grid geometry. CR itself has no advance: END is the canonical CR position, NEXT skips theCR. EOF END/NEXT equal the canonical scan position. On word wrapping SCAN may extend beyond the published END/NEXT; GL_REWIND1 means the caller must refetch from NEXT before starting its next line. The source suffix is never copied or changed.

No-wrap accumulates full24-bit logical x until CR/EOF with the same32-byte step bound, including logical lines longer than64KiB. Only contiguous glyphs intersecting `[pan,pan+width)` enter the visible map. The first/last boundary may be clipped; the next source index derives from canonical `GL_MAP_FIRST+index`, so no large per-position24-bit array is needed. An entirely invisible line maps its end boundary to its clamped x. Coordinates are checked against24-bit overflow (actual font max11×1MiB remains representable; arbitrary supplied255 advances may reach the explicit7B limit).

Published map count0..320 means count+1 valid little-endian viewport x words. A requested source caret is observed while streaming as logical24-bit x; caret validity is removed if a word-wrap rewind excludes it. CR/EOF end boundaries may own the caret; FULL/WORD/HARD/OVERWIDE end boundaries belong to the next line. The map itself still includes that canonical end boundary for click placement. HIT is allowed only in ready state, scans at most321 boundaries, clamps unsigned requested x to the viewport, picks the nearest boundary with midpoint ties toward the higher source index and returns canonical24-bit source plus its boundary index. Caller handles viewport reveal and geometry-specific caret assignment; this primitive does not paint or select source.

`python3 tests/test_geos_line.py` links the real emitted code and uses an independent Python wrap/advance/map/hit model.3094 lines,7153 packets and30666 hit tests pass, including lower/upper/fallback native glyphs, all bold/italic styles, literal spaces across packet seams, hard words/overwide glyphs, CR/EOF/exact320, the full321-entry map, anchors crossing64KiB,24-bit no-wrap pans and a66000-byte logical line processed in32-byte packets.13 invalid/state/offset/overflow cases pass. Every ordinary call checks all64KiB RAM outside frame/pointers/stack; hit batches also have a full guard. Source/fonts, catalog7F40..7FFF,1024-byte shim and512KiB REU remain exact.
