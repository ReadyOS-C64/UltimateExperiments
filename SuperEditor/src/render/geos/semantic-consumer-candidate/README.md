# Private automatic C21 semantic checkpoint consumer

This separate namespace preserves both earlier checkpoint releases. It adds the
actual C21 first-classify consumer to the released dual incoming C24 service.
No canonical files, shared builds, resident state, ZP, REU bank or asset added.
Root owns C23 and public pending-reveal routing; neither is changed here.

Build with `python3 src/render/geos/semantic-consumer-candidate/build.py OUT FIXTURE`.
On coherent combined48 `20261025T191455863964Z/fixture`, the actual original
C21/cache and C24/parser controls must reproduce their sealed SEO bytes exactly.
The private pair is **C21 4048/4096**, **C24 4062/4096**; controls3597/2781.

## Consumer and compatibility

Only after actual owner4 claim, C21 saves GEC_VALID into phase8BF3. At first
classify with no existing CP_VALID, the new PS13 continuation requests actual
C24 op3/selector0. On miss it tries selector1, then uses the original normal
C24 BEGIN. Accepted incoming CP_VALID2 also passes through normal BEGIN and
real parser feed; no semantic event or source glyph is manufactured. Existing
valid forward checkpoints use the original path without redundant probes.

Every optional probe and producer first requires actual published C24 slot1,
size4062 and raw CCITT47658 ($BA2A) from this exact binding/build. Managed slot
bit7 alone is ignored for slot identity; other slot bits must yield1. The real
loader continues its independent sealed-image/capability admission. An old or
mixed worker safely skips BOTH op3 and the new producer, because old workers
cannot initialize CAPTURED/incoming phase fields. Missing workers retain their
original actual loader error17; they are not silently treated as successful
rendering. Rebind/relink regenerates this exact witness; it is not a global
version number or authority to call arbitrary same-sized code.

The dual record/phase/lease contract is unchanged from
`semantic-previous-candidate/README.md`: typed FE0600..063F current and
0640..067F predecessor, V2/full28B source key/CR carry/viewportTOP/fullCRC,
VALID-last, selector0/1, owned R14 lease ended on every return. Actual source
tokens, generations, epochs, single-GEC prefix proof, fold/mode/provider guards
are not relaxed. C21 producer is still restricted to real LINE0 with
incomingSTART==TOP. It never guesses a shifted anchor or rekeys across flush.

## Actual public and recovery proof

`python3 tests/test_geos_semantic_consumer.py` runs seven public root cases with
only the two privately sealed SEO substitutions: near/far (>64KiB) INSERT,
BACK and CR split, plus a heading-prefix class change. Real C6 input, C21 root
job11, C24/R14 and ordinary row paint run. Every frame equals both the original
forced-full renderer and independent source/font pixel, attributes, all row
anchors, geometry and bottom oracles. Canonical source/history/caret/selection,
normalized catalog and protected C600..C9FF remain exact.

All16MiB are compared outside precisely declared FE header64, two64B records,
22 occupied ABI3 packet spans842B, GCC bitmap/attributes plus oldheader
B200..D567, and expanded BSW font E568..EA87. The obsolete R28 row backups
D568..E567 are kept exact, not masked merely because their addresses remain
reserved. Font and packet validation remain independent.

forced-full (not native cycles or total user latency): far body INSERT
387450/11866250, BACK321720/11853376; far CR split821872/11893463. A near CR

`python3 tests/test_geos_semantic_consumer_recovery.py` passes eight recovery
groups: actual checked-DMA bad current CRC forces BOTH probes to miss and real
BOF parse; next BACK uses freshly republished records; exact old2781 worker
with poisoned CAPTURED/incoming skips probe and producer; queued IRQ STOP at

foreign source lease survives render; actual C->resident->C admission under
foreign FILE owner refusesB2 before union phase access. Source/shim/full16MiB
scopes stay strict, including dead backups. Optional corruption never weakens
normal source or loader failures.

Limitations: source/frame preparation is an explicit CPU fixture, no real
KERNAL/VIC/IRQ timing claim. Root C23/public flush routing is untouched. Repeated
incremental publications below LINE0 may age the old full key beyond one GEC
and safely miss until a real producer refresh. No global PAGE171 or
before-TOP225M latency closure is claimed by this component alone.
