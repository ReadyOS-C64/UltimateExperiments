R29 combines the unchanged merged-source provider with 868 bytes of C21 per-row geometry, source packet, style and canonical-map work. Reader ops0/1/2 retain the existing ABI. Op3, owner4 only, authenticates the full page cache then dispatches PS1/2/3/7/8. C21 calls op3 synchronously and remains responsible for BEGIN, classification requests, fold/caret/edit R-slot calls, publication, finish and root job scheduling. C20/C24/C25/C26 privately target R29 instead of R14. No new resident code/state, ZP, ownership semantics or root continuation protocol.

Measured payloads: R29 4072, C21 2711 bytes. Full mixed and inline pages, pending edits, folds, the R28 dirty transaction and three live-lease cleanup/recovery cases agree with the independent font/source oracle and immutable full producer. R29 stays loaded for a normal unfolded page, but C21 still reloads after each C worker. Mixed CPU instructions improve about5%, inline about2.4%; a folded page is0.16% slower because R24 repeatedly evicts the larger reader. Recommendation: do not integrate this additional asset/routing complexity. This is CPU instruction evidence, not a native cycle claim.

A downstream batching ABI would need actual semantic descriptors rather than this helper alone. The helper consumes one live GL map; the next C20 BEGIN destroys that map. A bounded proposal is an eight-entry queue of32-byte logical-event descriptors in existing unused FE slot tails (slot+1814;234 bytes free per slot). Each descriptor contains canonical START/END/BODY9, KIND/LANG/LEVEL/MARKER4, ROLE/REVERSE/HEIGHT/INLINE4, and a sequence/flags byte; remaining14 reserved. A64-byte FE queue header at0040 can hold full source key28, canonical consumed/refill anchors6, head/count/capacity/status4 and epoch/fold/view witnesses. Queue writes must use exact source/provider and FE capability guards. No source prefixes or projection bytes replace canonical anchors.

C24 would fill at most eight complete logical events with bounded128-byte reads/32feeds per slice; C20 would measure/commit as many visual rows as those events cover, retaining partial-event anchors across soft wraps. After each complete visual row the live map must be persisted before another BEGIN. C25/C26 would return to that explicit batch continuation, not to a C21 admission per packet. A queue-empty or unsupported event returns a refill request; no dropped semantic/source guards. Folding can skip queued events only by authenticated canonical endpoints. First scope should be unfolded literal prose and fall back for folds/inline/code until their continuation ABI is proved. C20 currently has635 bytes free, R29 has24, so this requires measured repartitioning; it is not a drop-in extension and has not been implemented. The current candidate does not demonstrate that future gain.
