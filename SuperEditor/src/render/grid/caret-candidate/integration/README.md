# Private full-root integration

`python3 src/render/grid/caret-candidate/integration/build.py OUT` extracts the
immutable140326 product source ZIP into OUT/tree, copies host tools/fonts/data
and builds a wholly private resident plus all48 sealed images. It never runs a
shared build. The private fixture records its changed resident/allasset hashes
and exact modified source ZIP. Its D81 remains the untouched predecessor and
is explicitly **not** a48-image package/native fixture.

The integration relocates only the pure fold/layout decision from resident
`se_layout_prepare` into C33 operation2. Resident `se_ef_prepare` still performs
modal/key/rebuild admission first. C33op2 owns no frame and reads no phase union;
it returns0ready,1startC11,2requestAUXnowrapcontext. Resident still calls AUX and
C11 after C33 returns. No C-to-C nesting, no new state, no hidden cold dependency.
The common nofold/wrapped/needwrap0 predicate stays resident, preserving the
source40 zero-load path. The source40 loop adds8 instructions from mode/publication
hooks, not a command-image load.

The actual root calls C33op1 before normal60/80 rendering. Success clears redraw
and uses the existing publication body once. A miss/error falls back through
normal checked layout/render. Only the slow folded planner depends on C33;
missing/bad C33 there is a strict clean render failure before pixels. Full
publication calls optional C33CAPTURE after updating the real sequence/busy
fields; fast publication bypasses recapture. Capture failure cannot turn a
completed full frame into an error.

Measured linked budget: COLD080D–0EFE; CODE108F–3E2B; compact CORE3E2C–3E61;
RODATA3E62–3EFF; CRC3F00–3FFF; BSS1533 and ZP24 unchanged. C33 is3706B.
The private startup has48 table entries. GRID aliases GRIDEDIT's prefix, and the
failure hint is shortened to `Disk/REU?`; this saves two cold bytes and leaves
one byte before the fixed0F00 probe. The old cold sources are never called by
warm hooks. The existing provider/history/hot cold placement is not counted as
new reclamation.

The root comparison test is `tests/test_grid_caret_candidate_integration.py`.
It invokes actual root render/publication; there is no manual redraw/sequence
seam. Its other machine uses the unchanged47-image product as full reference.
`tests/test_grid_caret_candidate_faults.py` adds mandatory planner errors, real
C12FileOpen phase opacity (outstanding DIR, no DOS success claim), and actual
queuedSTOP of C11 plus recovery. `tests/test_grid_caret_candidate_stack.py`
extends only the released verifier's catalog-shape assertion from47 to exact48;
all binding/CRC/stage-byte-reassembly/CFG/opaque-call checks remain. It proves
relative foreground52 + oneIRQ/NMI16; no new native idle-SP capture is claimed.

Promotion remains a parent action: merge the three small source edits and C33
entry/plan, add its Make rule and package registration, then rebuild/reseal all48.
The root's newer C14span implementation must be preserved/rebuilt at promotion;
this fixture intentionally uses the immutable oldC14 as a controlled baseline.
Native timing, full current product lifecycle and48-image D81 are not claimed.
